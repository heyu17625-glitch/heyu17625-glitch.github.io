# 李三明·道意山水

本仓库维护 [李三明·道意山水网站](https://heyu17625-glitch.github.io/)。

在龙虎山的山水与道家自然观中寻找笔墨秩序，用真实作品、温和祝愿与空间美学连接当代生活。

## 内容

- 山水画与笔墨意境
- 虎画与传统意象
- 「今日如愿画」
- 东方空间配画
- 从第一滴墨到最后一方印的创作记录

品牌句：**山是稳，水是流，留白是呼吸。**

收束语：**愿见者如愿。**

## 本地构建

```bash
npm ci
npm run build
npm run verify:site
```

构建输入位于 `site/`，输出位于 `dist/`。

网站正文与图片采用《李三明道意山水·商业策划与全平台宣传成品包 V2》中的首发长文、九张图文画册及平台封面。
